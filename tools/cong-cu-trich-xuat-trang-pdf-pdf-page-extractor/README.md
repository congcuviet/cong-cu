# Công cụ trích xuất trang PDF – PDF Page Extractor

Lấy riêng một đoạn trang liên tục (một chương, một phần) ra khỏi file PDF lớn thành file mới, xử lý hoàn toàn trong trình duyệt.

👉 **Dùng trực tuyến:** https://congcuviet.com/cong-cu/cong-cu-trich-xuat-trang-pdf-pdf-page-extractor/

## Tính năng

- Chọn 1 file PDF bằng cách bấm hoặc kéo-thả, xem tổng số trang.
- Nhập khoảng trang cần lấy, hoặc dùng nút nhanh: trang đầu, trang cuối, nửa đầu, nửa sau, toàn bộ.
- Xem trước số trang sẽ trích xuất trước khi xử lý.
- Tải file PDF mới với tên chứa sẵn khoảng trang đã trích.

## Mã nguồn

- `pdf-page-extractor.php` — giao diện công cụ
- `pdf-page-extractor.css` — định dạng
- `pdf-page-extractor.js` — logic xử lý, chạy hoàn toàn phía trình duyệt

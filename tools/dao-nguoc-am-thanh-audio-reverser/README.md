# Đảo ngược âm thanh – Audio Reverser

Đảo ngược file âm thanh từ cuối lên đầu để tạo hiệu ứng âm thanh bí ẩn và độc đáo, xử lý ngay trong trình duyệt.

👉 **Dùng trực tuyến:** https://congcuviet.com/cong-cu/dao-nguoc-am-thanh-audio-reverser/

## Tính năng

- Chọn file âm thanh cần đảo ngược.
- Lật ngược toàn bộ âm thanh từ cuối lên đầu.
- Nghe thử kết quả và tải file đã đảo ngược về máy.

## Mã nguồn

- `audio-reverser.php` — giao diện công cụ
- `audio-reverser.css` — định dạng
- `audio-reverser.js` — logic đảo ngược âm thanh, chạy hoàn toàn phía trình duyệt

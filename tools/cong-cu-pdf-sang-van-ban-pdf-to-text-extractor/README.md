# Công cụ PDF sang văn bản – PDF to Text Extractor

Trích xuất toàn bộ lớp chữ trong file PDF thành văn bản thuần để sao chép hoặc tải về dạng .txt.

👉 **Dùng trực tuyến:** https://congcuviet.com/cong-cu/cong-cu-pdf-sang-van-ban-pdf-to-text-extractor/

## Tính năng

- Chọn 1 file PDF, xem số trang rồi trích xuất từng trang.
- Tùy chọn chèn dòng phân cách theo trang để biết đoạn chữ thuộc trang nào.
- Sửa trực tiếp văn bản đã trích, sao chép hoặc tải file .txt, kèm thống kê số trang có chữ, số từ và số ký tự.

## Mã nguồn

- `pdf-to-text.php` — giao diện công cụ
- `pdf-to-text.css` — định dạng
- `pdf-to-text.js` — logic xử lý, chạy hoàn toàn phía trình duyệt

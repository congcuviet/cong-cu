# Công cụ xoay PDF – Rotate PDF

Xoay các trang PDF bị ngược hoặc nằm ngang về đúng chiều và tải file mới, xử lý 100% trong trình duyệt.

👉 **Dùng trực tuyến:** https://congcuviet.com/cong-cu/cong-cu-xoay-pdf-rotate-pdf/

## Tính năng

- Chọn file PDF bằng cách bấm chọn hoặc kéo & thả.
- Chọn góc xoay: 90° sang phải, 180° lật ngược hoặc 90° sang trái.
- Chọn trang áp dụng; để trống để xoay mọi trang.
- Tải file PDF đã xoay về máy; file gốc không bị thay đổi và không tải lên máy chủ.

## Mã nguồn

- `rotate-pdf.php` — giao diện công cụ
- `rotate-pdf.css` — định dạng
- `rotate-pdf.js` — logic xử lý PDF, chạy hoàn toàn phía trình duyệt

# Công cụ kiểm tra mã trạng thái HTTP (HTTP Status Checker)

Kiểm tra mã trạng thái HTTP của một địa chỉ website, kèm mô tả phản hồi và thời gian phản hồi.

👉 **Dùng trực tuyến:** https://congcuviet.com/cong-cu/cong-cu-kiem-tra-ma-trang-thai-http-http-status-checker/

## Tính năng

- Nhập URL website cần kiểm tra, tự thêm https:// khi thiếu.
- Xem mã HTTP STATUS CODE cùng mô tả phản hồi.
- Xem thời gian phản hồi (Ping) và URL đích được quét trong thông số phản hồi.

## Mã nguồn

- `http-neo-wrapper2.php` — giao diện công cụ
- `http-neo-wrapper2.css` — định dạng
- `http-neo-wrapper2.js` — logic xử lý, chạy hoàn toàn phía trình duyệt

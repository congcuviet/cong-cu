# Công cụ đặt mật khẩu cho PDF – Protect PDF

Đặt mật khẩu mở file cho PDF bằng mã hóa AES-256, xử lý hoàn toàn trong trình duyệt, không tải file lên máy chủ.

👉 **Dùng trực tuyến:** https://congcuviet.com/cong-cu/cong-cu-protect-pdf/

## Tính năng

- Chọn 1 file PDF bằng cách bấm hoặc kéo-thả.
- Đặt mật khẩu mở file (ít nhất 4 ký tự), thêm mật khẩu chủ sở hữu riêng và khóa quyền in/sao chép/chỉnh sửa khi cần.
- Tạo file PDF đã mã hóa và tải về, mở thử để kiểm tra trước khi gửi.

## Mã nguồn

- `protect-pdf.php` — giao diện công cụ
- `protect-pdf.css` — định dạng
- `protect-pdf.js` — logic xử lý, chạy hoàn toàn phía trình duyệt

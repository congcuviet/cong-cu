# Công cụ nén file PDF – Compress PDF

Giảm dung lượng file PDF để dễ gửi email, tải lên hệ thống hoặc nộp hồ sơ trực tuyến, xử lý ngay trên trình duyệt.

👉 **Dùng trực tuyến:** https://congcuviet.com/cong-cu/cong-cu-nen-file-pdf-compress-pdf/

## Tính năng

- Chọn 1 file PDF bằng cách bấm hoặc kéo-thả, xem dung lượng gốc và số trang.
- Chọn chế độ nén mạnh (qua ảnh) cho file scan hoặc nén nhẹ (giữ nguyên chữ).
- Xem so sánh dung lượng trước/sau và phần trăm tiết kiệm, rồi tải file đã nén.

## Mã nguồn

- `compress-pdf.php` — giao diện công cụ
- `compress-pdf.css` — định dạng
- `compress-pdf.js` — logic xử lý, chạy hoàn toàn phía trình duyệt

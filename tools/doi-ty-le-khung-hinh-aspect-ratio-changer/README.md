# Đổi tỷ lệ khung hình – Aspect Ratio Changer

Đổi tỷ lệ khung hình của video ngay trong trình duyệt, không tải video lên máy chủ, không watermark.

👉 **Dùng trực tuyến:** https://congcuviet.com/cong-cu/doi-ty-le-khung-hinh-aspect-ratio-changer/

## Tính năng

- Tải video lên bằng cách chọn file hoặc kéo thả.
- Tỷ lệ mới: 9:16 dọc, 16:9 ngang, 1:1 vuông, 4:5, 4:3, 3:4, 21:9 phim.
- Ba cách đặt hình vào khung mới: thêm viền, cắt lấp đầy hoặc kéo giãn.
- Tùy chọn viền đen hoặc viền trắng, vị trí cắt giữa/trái/trên/phải/dưới.
- Xem trước khung hình trước khi đổi; file xuất ra vẫn giữ tiếng gốc.

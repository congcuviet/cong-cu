# Công cụ làm phẳng PDF – PDF Flatten Tool

Làm phẳng file PDF biểu mẫu — gộp các ô đã điền thành nội dung cố định của trang trước khi nộp hoặc gửi đi.

👉 **Dùng trực tuyến:** https://congcuviet.com/cong-cu/cong-cu-pdf-flatten-tool/

## Tính năng

- Chọn file PDF biểu mẫu bằng cách bấm hoặc kéo-thả, công cụ tự động làm phẳng ngay.
- Xem số trường biểu mẫu đã được làm phẳng.
- Tải file PDF đã làm phẳng và kiểm tra lại trước khi nộp.

## Mã nguồn

- `pdf-flatten.php` — giao diện công cụ
- `pdf-flatten.css` — định dạng
- `pdf-flatten.js` — logic xử lý, chạy hoàn toàn phía trình duyệt

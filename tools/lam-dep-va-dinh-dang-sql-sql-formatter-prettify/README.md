# Làm đẹp và Định dạng SQL (SQL Formatter & Prettify)

Làm đẹp, nén và kiểm tra cú pháp câu lệnh SQL ngay trên trình duyệt — hỗ trợ 8 phương ngữ SQL phổ biến, kèm kiểm tra an toàn trước khi chạy.

👉 **Dùng trực tuyến:** https://congcuviet.com/cong-cu/lam-dep-va-dinh-dang-sql-sql-formatter-prettify/

## Tính năng

- Làm đẹp (prettify) hoặc nén (minify) câu lệnh SQL với thụt lề tùy chỉnh.
- Hỗ trợ 8 phương ngữ: Standard, MySQL, MariaDB, PostgreSQL, SQLite, SQL Server (T-SQL), Oracle (PL/SQL) và BigQuery.
- Kiểm tra an toàn, cảnh báo trước các câu lệnh có thể gây rủi ro.
- Ví dụ có sẵn: truy vấn JOIN, CASE + truy vấn lồng, CREATE TABLE.
- Sao chép kết quả hoặc tải về dưới dạng .sql.
- Mọi thao tác thực hiện 100% trên trình duyệt, dữ liệu không gửi lên máy chủ.

## Mã nguồn

- `sql-formatter-v2.php — giao diện công cụ`
- `sql-formatter-v2.css — định dạng`
- `sql-formatter-v2.js — logic làm đẹp, nén và kiểm tra SQL`

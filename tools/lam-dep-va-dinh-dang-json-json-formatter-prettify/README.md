# Làm đẹp và Định dạng JSON (JSON Formatter & Prettify)

Làm đẹp, nén và kiểm tra cú pháp JSON ngay trên trình duyệt — thụt lề theo ý muốn, báo lỗi cú pháp rõ vị trí, hỗ trợ tải tệp .json và xuất kết quả.

👉 **Dùng trực tuyến:** https://congcuviet.com/cong-cu/lam-dep-va-dinh-dang-json-json-formatter-prettify/

## Tính năng

- Làm đẹp JSON với thụt lề 2 hoặc 4 dấu cách, hoặc nén gọn thành một dòng.
- Kiểm tra cú pháp và báo lỗi kèm vị trí, kèm cảnh báo khi dữ liệu có điểm bất thường.
- Tải tệp .json lên để xử lý, sao chép kết quả hoặc tải về dưới dạng .json.
- Ví dụ có sẵn (object, dữ liệu API) để thử ngay.
- Mọi thao tác thực hiện 100% trên trình duyệt, dữ liệu không gửi lên máy chủ.

## Mã nguồn

- `json-formatter-v2.php — giao diện công cụ`
- `json-formatter-v2.css — định dạng`
- `json-formatter-v2.js — logic làm đẹp, nén và kiểm tra JSON`

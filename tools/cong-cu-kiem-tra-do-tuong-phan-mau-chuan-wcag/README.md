# Công cụ kiểm tra độ tương phản màu chuẩn WCAG

Kiểm tra tỷ lệ tương phản giữa màu chữ và màu nền theo tiêu chuẩn WCAG, kèm kết quả PASS/FAIL cho chữ thường, chữ lớn và thành phần phi văn bản.

👉 **Dùng trực tuyến:** https://congcuviet.com/cong-cu/cong-cu-kiem-tra-do-tuong-phan-mau-chuan-wcag/

## Tính năng

- Nhập màu chữ và màu nền bằng ô chọn màu hoặc mã màu, hỗ trợ mã 3 ký tự.
- Xem tỷ lệ tương phản cùng kết luận và trạng thái PASS/FAIL theo từng mức AA/AAA.
- Tự sửa cặp màu về mức AA và đảo ngược cặp màu khi cần.
- Sao chép kết quả gồm tỷ lệ và toàn bộ trạng thái PASS/FAIL.

## Mã nguồn

- `wcag-contrast-checker-v2.php` — giao diện công cụ
- `wcag-contrast-checker-v2.css` — định dạng
- `wcag-contrast-checker-v2.js` — logic xử lý, chạy hoàn toàn phía trình duyệt

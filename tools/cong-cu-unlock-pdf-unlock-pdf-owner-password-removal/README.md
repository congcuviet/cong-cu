# Công cụ gỡ mật khẩu PDF – Unlock PDF

Gỡ mật khẩu khỏi file PDF của chính bạn khi bạn biết đúng mật khẩu hiện tại, xử lý hoàn toàn trong trình duyệt, file không tải lên máy chủ.

👉 **Dùng trực tuyến:** https://congcuviet.com/cong-cu/cong-cu-unlock-pdf-unlock-pdf-owner-password-removal/

## Tính năng

- Chọn 1 file PDF bằng cách bấm hoặc kéo-thả.
- Nhập mật khẩu hiện tại của file; file chỉ bị khóa quyền in/sửa thì để trống ô mật khẩu.
- Tạo file PDF mới mở không cần mật khẩu và không còn giới hạn quyền.
- Mở thử file mới ngay để xác nhận trước khi xóa bản gốc.

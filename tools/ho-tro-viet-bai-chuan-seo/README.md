# Hỗ trợ viết bài chuẩn SEO

Soạn thảo và kiểm tra bài viết chuẩn SEO ngay trên trình duyệt: chấm điểm SEO tổng theo thang 100, kiểm tra tiêu đề, meta description, slug và mật độ từ khóa.

👉 **Dùng trực tuyến:** https://congcuviet.com/cong-cu/ho-tro-viet-bai-chuan-seo/

## Tính năng

- Nhập từ khóa chính và từ khóa phụ, tên miền, tiêu đề SEO, slug và mô tả meta.
- Đếm ký tự tiêu đề (chuẩn 60) và mô tả meta (chuẩn 160).
- Chấm điểm SEO tổng trên thang 100 với gợi ý cải thiện.
- Công cụ xử lý nhanh: highlight từ khóa, xóa dòng trắng thừa, chỉnh ảnh, đồng bộ ALT ảnh theo caption, in đậm heading.
- Nạp bài mẫu, sao chép HTML và tải file .html.

## Mã nguồn

- `seo-editor-v2.php — giao diện công cụ`
- `seo-editor-v2.css — định dạng`
- `seo-editor-v2.js — logic soạn thảo và chấm điểm SEO`

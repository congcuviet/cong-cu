# Công cụ thêm số trang vào file PDF – Add Page Numbers to PDF

Đánh số trang tự động cho tài liệu, luận văn, báo cáo PDF — số được in hẳn vào trang nên in ra giấy vẫn có.

👉 **Dùng trực tuyến:** https://congcuviet.com/cong-cu/cong-cu-them-so-trang-vao-file-pdf-add-page-numbers-to-pdf/

## Tính năng

- Chọn 1 file PDF bằng cách bấm hoặc kéo-thả, xem tên file và tổng số trang.
- Chọn kiểu hiển thị (ví dụ “Trang 1 / 10”), vị trí, cỡ chữ và số bắt đầu; tùy chọn bỏ qua trang đầu tiên.
- Đánh số và tải file PDF đã đánh số, kiểm tra vài trang đầu/cuối trước khi gửi.

## Mã nguồn

- `add-page-numbers-pdf.php` — giao diện công cụ
- `add-page-numbers-pdf.css` — định dạng
- `add-page-numbers-pdf.js` — logic xử lý, chạy hoàn toàn phía trình duyệt

# Ghép nhạc Online – Audio Joiner / Merger

Ghép nhiều tệp âm thanh thành một bản duy nhất ngay trên trình duyệt, với tùy chọn nối thẳng, crossfade hoặc khoảng lặng giữa các đoạn.

👉 **Dùng trực tuyến:** https://congcuviet.com/cong-cu/ghep-nhac-online-audio-joiner-merger/

## Tính năng

- Kéo thả hoặc chọn nhiều tệp âm thanh: MP3, M4A, WAV, OGG, FLAC và tiếng của video.
- Sắp xếp lại thứ tự ghép bằng kéo thả hoặc nút mũi tên.
- Chọn cách nối các đoạn: nối thẳng, crossfade, hoặc khoảng lặng với thời gian tùy chỉnh.
- Mờ dần ở đầu và cuối bản ghép.
- Nghe thử bản ghép và tải về file WAV 16-bit.
- Mọi xử lý diễn ra trên trình duyệt, không tải file lên máy chủ.

- `audio-joiner-v2.css — định dạng`

# Đọc văn bản (TTS) – Text to Speech

Đọc văn bản tiếng Việt thành giọng nói bằng mô hình AI chạy ngay trên máy của bạn, không gửi văn bản lên máy chủ.

👉 **Dùng trực tuyến:** https://congcuviet.com/cong-cu/doc-van-ban-tts-text-to-speech/

## Tính năng

- Nhập văn bản (tối đa 1.000 ký tự) kèm câu mẫu chào hỏi, bản tin, kể chuyện.
- Chọn giọng đọc và tốc độ từ 0,75× đến 2×; tốc độ áp trực tiếp vào file âm thanh tạo ra.
- Hai mô hình: Lite (Nano) nhẹ máy và Turbo giọng hay hơn (tải thêm khoảng 210 MB ở lần đầu).
- Tải file WAV, phụ đề .SRT và .TXT khớp mốc thời gian với âm thanh đã tạo.

## Mã nguồn

- `text-to-speech-v7.php` — giao diện công cụ
- `text-to-speech-v7.css` — định dạng
- `text-to-speech-v7.js` — logic đọc văn bản, chạy hoàn toàn phía trình duyệt

# Làm đẹp và Định dạng XML (XML Formatter & Prettify)

Làm đẹp, nén và kiểm tra cú pháp XML ngay trên trình duyệt — thụt lề theo ý muốn, báo lỗi cú pháp rõ ràng, hỗ trợ tải tệp .xml.

👉 **Dùng trực tuyến:** https://congcuviet.com/cong-cu/lam-dep-va-dinh-dang-xml-xml-formatter-prettify/

## Tính năng

- Làm đẹp (prettify) hoặc nén (minify) tài liệu XML với thụt lề 2 hoặc 4 dấu cách.
- Kiểm tra cú pháp well-formed và báo lỗi rõ vị trí khi XML sai.
- Phần tử rỗng được viết dạng tự đóng, ví dụ `<item/>`.
- Tải tệp .xml lên để xử lý, sao chép kết quả hoặc tải về dưới dạng .xml.
- Ví dụ có sẵn: XML lồng nhau, nội dung xen kẽ, XML lỗi để thử.
- Mọi thao tác thực hiện 100% trên trình duyệt, dữ liệu không gửi lên máy chủ.

## Mã nguồn

- `xml-formatter-v2.php — giao diện công cụ`
- `xml-formatter-v2.css — định dạng`
- `xml-formatter-v2.js — logic làm đẹp, nén và kiểm tra XML`

# Escape/Unescape ký tự HTML – Escape HTML entities

Mã hóa (escape) và giải mã (unescape) ký tự HTML sang dạng entity theo tên, số thập phân hoặc số hex — hữu ích khi chèn mã HTML vào bài viết, tài liệu hoặc đoạn code mẫu.

👉 **Dùng trực tuyến:** https://congcuviet.com/cong-cu/escape-unescape-ky-tu-html-escape-html-entities/

## Tính năng

- Mã hóa và giải mã hai chiều, chuyển đổi qua lại nhanh chóng.
- Chọn kiểu entity: theo tên (&lt;), số thập phân (&#60;) hoặc số hex (&#x3C;).
- Chọn phạm vi mã hóa: 5 ký tự cốt lõi, 8 ký tự, hoặc tất cả ký tự không ASCII.
- Sao chép kết quả, tải file .txt và giải thêm một lớp mã hóa.
- Bảng tham chiếu 8 ký tự được mã hóa kèm tên, số thập phân và số hex.

# Công cụ URL Encode và Decode

Mã hóa và giải mã chuỗi URL theo 3 phạm vi: tham số, URL đầy đủ và form (dấu +), với quy tắc chuyển đổi rõ ràng cho từng phạm vi.

👉 **Dùng trực tuyến:** https://congcuviet.com/cong-cu/cong-cu-url-encode-va-decode/

## Tính năng

- Chọn chế độ mã hóa (Encode) hoặc giải mã (Decode) và phạm vi: Tham Số, URL đầy đủ hoặc Form.
- Nhập nội dung, kết quả hiện ngay kèm thống kê và ví dụ nhanh (tìm kiếm tiếng Việt, C++, URL đầy đủ).
- Đảo chiều, sao chép kết quả, tải kết quả dạng văn bản hoặc giải mã thêm 1 lớp khi cần.
- Xem quy tắc chuyển đổi chi tiết theo từng phạm vi ngay trong công cụ.

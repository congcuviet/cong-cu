# Công cụ vẽ đồ thị hàm số (Graphing Calculator)

Vẽ đồ thị hàm số ngay trên trình duyệt: nhập biểu thức, tùy chỉnh khoảng trục tọa độ và màu nét vẽ để xem đồ thị trực quan.

👉 **Dùng trực tuyến:** https://congcuviet.com/cong-cu/cong-cu-ve-do-thi-ham-so-graphing-calculator/

## Tính năng

- Nhập hàm số tự do dạng f(x), y = ... hoặc biểu thức rút gọn (gõ 2x, x2, sin(2x) đều được, dấu thập phân chấm hoặc phẩy).
- Hàm mẫu sẵn có: đa thức, lượng giác, phân thức để thử ngay.
- Tùy chỉnh khoảng X Min/X Max, Y Min/Y Max và màu nét vẽ.
- Sao chép biểu thức và tải đồ thị dạng ảnh PNG.

## Mã nguồn

- `graphing-calculator-v2.php` — giao diện công cụ
- `graphing-calculator-v2.css` — định dạng
- `graphing-calculator-v2.js` — logic vẽ đồ thị, chạy hoàn toàn phía trình duyệt

# Công cụ xóa trang trong file PDF – Delete PDF Pages

Xóa các trang không cần thiết khỏi file PDF và tạo file mới giữ nguyên thứ tự các trang còn lại, xử lý 100% trong trình duyệt.

👉 **Dùng trực tuyến:** https://congcuviet.com/cong-cu/cong-cu-xoa-trang-trong-file-pdf-delete-pdf-pages/

## Tính năng

- Chọn file PDF bằng cách bấm chọn hoặc kéo & thả.
- Nhập số trang hoặc khoảng trang cần xóa, cách nhau bằng dấu phẩy.
- Xem thống kê số trang đã xóa, số trang còn lại và dung lượng file mới.
- Tải file PDF mới về máy; file gốc không bị thay đổi và không tải lên máy chủ.

## Mã nguồn

- `delete-pdf-pages.php` — giao diện công cụ
- `delete-pdf-pages.css` — định dạng
- `delete-pdf-pages.js` — logic xử lý PDF, chạy hoàn toàn phía trình duyệt

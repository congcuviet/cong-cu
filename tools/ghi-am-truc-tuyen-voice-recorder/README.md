# Ghi âm Trực tuyến – Voice Recorder

Ghi âm trực tiếp bằng micro ngay trên trình duyệt, có sóng âm theo thời gian thực, chỉnh micro và tải về file WAV.

👉 **Dùng trực tuyến:** https://congcuviet.com/cong-cu/ghi-am-truc-tuyen-voice-recorder/

## Tính năng

- Ghi âm bằng micro của thiết bị, sóng âm chạy theo tiếng thu được.
- Tạm dừng, dừng lại hoặc hủy bản ghi đang thu.
- Cài đặt micro: chọn micro, khử tiếng vang, lọc nhiễu nền, tự chỉnh âm lượng.
- Nghe thử bản ghi và tải về file WAV 16-bit (hoặc định dạng gốc).
- Cắt khoảng lặng ở đầu và cuối khi xuất WAV.
- Bản ghi chỉ xử lý trên trình duyệt, không tải lên máy chủ.

## Mã nguồn

- `voice-recorder-v2.php — giao diện công cụ`
- `voice-recorder-v2.css — định dạng`
- `voice-recorder-v2.js — logic ghi âm`

# Làm đẹp và Định dạng YAML (YAML Formatter & Prettify)

Làm đẹp, nén và kiểm tra cú pháp YAML ngay trên trình duyệt — thụt lề theo ý muốn, báo lỗi cú pháp rõ ràng, hỗ trợ tải tệp .yaml.

👉 **Dùng trực tuyến:** https://congcuviet.com/cong-cu/lam-dep-va-dinh-dang-yaml-yaml-formatter-prettify/

## Tính năng

- Làm đẹp (prettify) hoặc nén (minify) tài liệu YAML với thụt lề 2 hoặc 4 khoảng trắng.
- Kiểm tra cú pháp và báo lỗi rõ vị trí khi YAML sai.
- Tải tệp .yaml lên để xử lý, sao chép kết quả hoặc tải xuống.
- Ví dụ có sẵn: cấu hình ứng dụng, file Docker Compose.
- Mọi thao tác thực hiện 100% trên trình duyệt, dữ liệu không gửi lên máy chủ.

## Mã nguồn

- `yaml-formatter-v2.php — giao diện công cụ`
- `yaml-formatter-v2.css — định dạng`
- `yaml-formatter-v2.js — logic làm đẹp, nén và kiểm tra YAML`

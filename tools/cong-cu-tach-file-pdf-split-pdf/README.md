# Công cụ tách file PDF – Split PDF

Tách một file PDF thành nhiều file theo khoảng trang, hoặc mỗi trang thành một file riêng, ngay trong trình duyệt.

👉 **Dùng trực tuyến:** https://congcuviet.com/cong-cu/cong-cu-tach-file-pdf-split-pdf/

## Tính năng

- Chọn 1 file PDF, xem tên file, dung lượng và tổng số trang.
- Tách theo khoảng trang (ví dụ 1-3, 5, 7-9) hoặc tách mỗi trang thành 1 file.
- Tải từng file kết quả với tên gợi nhớ khoảng trang, kèm số trang và dung lượng.

## Mã nguồn

- `split-pdf.php` — giao diện công cụ
- `split-pdf.css` — định dạng
- `split-pdf.js` — logic xử lý, chạy hoàn toàn phía trình duyệt

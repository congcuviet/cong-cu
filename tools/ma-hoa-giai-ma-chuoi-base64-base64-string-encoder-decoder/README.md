# Mã hóa/Giải mã chuỗi Base64 – Base64 string encoder/decoder

Mã hóa văn bản sang Base64 và giải mã chuỗi Base64 về văn bản gốc, ngay trên trình duyệt — hỗ trợ bảng chữ cái chuẩn, URL-safe và dạng rút gọn không dấu `=`.

👉 **Dùng trực tuyến:** https://congcuviet.com/cong-cu/ma-hoa-giai-ma-chuoi-base64-base64-string-encoder-decoder/

## Tính năng

- Mã hóa (encode) văn bản thuần sang chuỗi Base64 và giải mã (decode) ngược lại.
- Bảng chữ cái chuẩn (`+` `/`) hoặc URL-safe (`-` `_`).
- Tùy chọn không thêm dấu `=` ở cuối — dạng rút gọn thường dùng cho JWT.
- Hỗ trợ chuỗi có tiền tố `data:...;base64,`.
- Sao chép kết quả hoặc tải về dưới dạng .txt.
- Mọi thao tác thực hiện 100% trên trình duyệt, dữ liệu không gửi lên máy chủ.
